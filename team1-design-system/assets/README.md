Use `asset-index.json` to select assets by role and verify any status warning. The source files were extracted from the authoritative Team1 presentation and renamed without visual modification.

## Folders

- `logos/` — Team1, Avalanche, Ambassador DAO, and one regional source mark. Never alter these files.
- `backgrounds/` — dark/light, framed/unframed presentation canvases. Dark is the established primary mode.
- `chapters/` — source chapter/region tiles with baked labels. Confirm current approval before reuse.
- `icons/` — source metric tiles with baked numbers. Treat the numbers as time-sensitive claims.
- `graphics/` — expressive wireframe, mosaic, partner, and cinematic devices.
- `photography/` — documentary community imagery from the source deck. Confirm reuse rights and context.

The complete visual index is also available at `../previews/asset-contact-sheet.png` from the skill root.
