# Ready-to-use prompts

These prompts work across agent harnesses. Replace bracketed fields with verified information.

## Create an event deck

> Use the `team1-design-system` skill and the bundled editable presentation. Build a [slide count]-slide Team1 deck for [audience] in [language]. The audience should [outcome]. Use only these verified facts: [facts]. Use these approved links/photos/partner marks: [assets]. Map every output slide to a bundled template frame, preserve inherited Team1 furniture, render every slide, fix visual defects, and deliver the editable deck plus PDF.

## Apply Team1 to an existing presentation

> Use the `team1-design-system` skill to restyle this presentation without changing its factual meaning. First inventory the source presentation and map each output page to a bundled Team1 frame. Preserve the Team1 master/layout system, authentic logos, semantic red roles, typography mode, and documentary image language. Flag stale or unverified claims instead of publishing them. Deliver an editable copy and the requested export after visual QA.

## Create social and print collateral

> Use the `team1-design-system` skill to create a [format/dimensions] asset for [channel]. Read the brand and collateral references. Treat platform dimensions and safe areas as derived production guidance, not official Team1 law. Use this exact approved copy: [copy]. Use this approved photo/link: [asset]. Do not invent a QR, event fact, partner, or chapter identity. Inspect the final export at thumbnail and full size.

## Review an artifact

> Review this artifact with the `team1-design-system` skill. Do not redesign it. Report evidence-backed issues in priority order across brand integrity, logos, red roles, typography mode, imagery, factual freshness, layout, accessibility, and export quality. Distinguish an observed Team1 rule from a derived recommendation.

## Test that the skill loaded

> Use the Team1 design system to outline a three-slide local meetup deck and name the exact bundled frame and asset path for each slide. Also state the two typography modes, the three red roles, and the final QA file you will use.
