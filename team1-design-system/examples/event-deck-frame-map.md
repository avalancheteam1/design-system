# Example: current event-deck frame map

This is a planning example, not approved event content. Inspect all 40 exemplars in `templates/Team1 Current Presentation Template.pptx` before selecting exact slide numbers; source revisions may reorder exemplars.

| Output | Narrative job | Current master archetype | Required checks |
|---|---|---|---|
| 1 | Cover | dark cover | verified event name/date/location; current marks |
| 2 | Purpose | dark title + body | one message; no stale placeholder text |
| 3 | Context | light title + body | source/date for facts; contrast |
| 4 | Program | dark three-item grid | parallel copy; equal density |
| 5 | Experience | image-left/right | approved crop and rights record |
| 6 | Proof | quote or large-copy | attributable, approved statement |
| 7 | Comparison | inherited comparison table | native text; short, parallel rows |
| 8 | Next steps | inherited three-card layout | owners and dates verified |
| 9 | CTA | approved QR archetype | verified URL, visible fallback, export scan |
| 10 | Closing | inherited closing | one action; no duplicate QR by default |

Duplicate existing frames and edit their objects. Preserve the master/layout, mixed styles, media aspect ratios, footer, page system, and dark/light cadence. Shorten copy or change archetype before shrinking type.
