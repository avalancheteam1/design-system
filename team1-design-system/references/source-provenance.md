## Asset treatment

Current global identity assets were compared with the pinned common repository. Approved assets shipped by this package are indexed with their checksums and use status. Always choose them through `assets/asset-index.json`; never recreate a logo from this prose.

No font binary is evidence of a redistribution license. Aeonik is commercial, Neuropol X licensing was unresolved, and Inter/Kanit require their applicable license when redistributed. This package therefore documents acquisition/use requirements rather than treating source access as a license.

Participant photos, headshots, member/contact data, applications, attendance records, live QR payloads, raw footage/audio, recordings, third-party partner marks, social screenshots, source campaign files, archive assets, and `_OLD`/migration material are excluded by default. Use them only through a separate approved rights record.

## Time-sensitive content

Metrics, chapter status, program names, application routes, dates, social handles, partners, event names, calls to action, and QR destinations are mutable. Their appearance in a source proves a prior visual treatment, not present approval. Verify each item with an owner and date before publication.

## Known limits

- The private common repository contained no repository license/notice establishing public redistribution rights; organizational access alone is not public permission.
- Some source binaries were too large for connector materialization, but their canonical local or repository sources were used where available.
- An externally linked regional style guide was inaccessible; observed regional layouts were treated as evidence, not as a replacement for the global guide.
- Existing print and merchandise files do not establish universal vendor specifications; each job still requires vendor preflight and proofing.

Re-run the authority drift check before each release and update this file with the new commit, source dates, exceptions, and inspection coverage.
